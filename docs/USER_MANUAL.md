## Getting Started

### System Requirements
- **Device**: Desktop, laptop, tablet, or smartphone
- **Browser**: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- **Internet**: Stable connection required for real-time features
- **Screen Resolution**: Minimum 1024x768 recommended

### First Login
1. Open your browser and navigate to your StoreWise URL
2. Enter your email and password provided by your administrator
3. Select your outlet if you work at multiple locations
4. Click "Sign in"

### Dashboard Introduction
After login, you'll see the main dashboard with:
- **Navigation Menu**: Left sidebar with all main features
- **KPI Cards**: Today's sales, transactions, customers, and stock alerts
- **Charts**: Sales trends and category breakdowns
- **Quick Actions**: Easy access to common tasks

## Point of Sale (POS)

### Starting a Sale

#### 🛍️ Adding Products to Cart
1. **Search Method 1**: Use the search bar to find products by name or SKU
2. **Search Method 2**: Browse by category using the filter dropdown
3. **Search Method 3**: Scan product barcode (if barcode scanner connected)
4. **Add to Cart**: Click on any product to add it to the current sale

#### ✏️ Modifying Cart Items
- **Increase Quantity**: Click the `+` button next to the item
- **Decrease Quantity**: Click the `-` button next to the item
- **Remove Item**: Click the trash icon to remove from cart
- **Adjust Price**: Select item and apply discount if authorized

#### 💳 Payment Processing
1. **Review Cart**: Verify all items and total amount
2. **Select Payment Method**: Choose from Cash, Card, Mobile, or Bank Transfer
3. **Cash Payment**: Enter amount received to calculate change
4. **Card Payment**: Follow on-screen prompts for card processing
5. **Complete Sale**: Click "Complete Payment" to finalize

#### 🧾 Receipt Options
- **Print Receipt**: Automatic receipt printing (if printer connected)
- **Email Receipt**: Send digital receipt to customer email
- **SMS Receipt**: Send receipt via SMS (if customer number provided)
- **No Receipt**: Choose not to provide receipt for small purchases

### Advanced POS Features

#### 🔍 Product Search Tips
- **Partial Matches**: Type partial product names
- **SKU Search**: Enter exact SKU for precise results
- **Category Filter**: Narrow down search by product category
- **Barcode Scanner**: Connect USB barcode scanner for faster checkout

#### 💡 Product Information
- **Stock Levels**: Real-time inventory count displayed
- **Pricing**: See both cost and selling prices (if authorized)
- **Product Details**: Click product name for more information
- **Batch Information**: View expiry dates for perishable items

#### 🎯 Quick Actions
- **Hold Sale**: Temporarily save a sale for later completion
- **Void Item**: Remove specific items with reason code
- **Discount**: Apply percentage or fixed amount discounts
- **Customer Assignment**: Link sale to customer for loyalty points

## Product Management

### Adding New Products

#### 📦 Basic Product Information
1. **Product Name**: Descriptive name customers will recognize
2. **SKU Code**: Unique stock-keeping unit code
3. **Category**: Organize products by type (Electronics, Food, etc.)
4. **Brand**: Manufacturer or brand name
5. **Description**: Detailed product description for search

#### 💰 Pricing and Inventory
1. **Cost Price**: What you pay for the product
2. **Selling Price**: What customers pay
3. **Initial Stock**: Starting inventory quantity
4. **Minimum Stock**: Alert level for reordering
5. **Maximum Stock**: Maximum inventory to hold

#### 🏷️ Advanced Settings
1. **Barcodes**: Add multiple barcodes for the same product
2. **Product Images**: Upload product photos for POS display
3. **Specifications**: Add detailed specifications (size, weight, etc.)
4. **Tags**: Add searchable tags for better organization

### Managing Existing Products

#### ✏️ Editing Products
1. **Navigate**: Go to Products → Product List
2. **Search**: Find the product using search or filters
3. **Edit**: Click the edit button next to the product
4. **Update**: Make changes and save
5. **Sync**: Changes are immediately available in POS

#### 🗑️ Deleting Products
1. **Find Product**: Locate the product in the product list
2. **Delete**: Click the delete button
3. **Confirm**: Confirm deletion with reason
4. **Archive**: Product is archived but data is preserved

#### 📊 Product Analytics
- **Sales History**: View product sales over time
- **Stock Movement**: Track inventory changes
- **Profit Margins**: Analyze product profitability
- **Customer Preferences**: See who buys which products

### Category Management

#### 📂 Creating Categories
1. **Hierarchy**: Create parent and sub-categories
2. **Naming**: Use clear, customer-friendly names
3. **Images**: Add category images for better visualization
4. **Sorting**: Arrange categories in logical order

## Inventory Management

### Stock Overview

#### 📈 Real-time Stock Levels
- **Current Stock**: Live inventory count per product
- **Stock Value**: Total value of current inventory
- **Low Stock Alerts**: Automatic alerts for reordering
- **Expiry Tracking**: Monitor product expiration dates

#### 📋 Stock Movements
- **Inbound**: Stock coming from suppliers
- **Outbound**: Stock going out through sales
- **Adjustments**: Manual stock corrections
- **Transfers**: Move stock between locations

### Stock Adjustments

#### 🔧 Manual Adjustments
1. **Reason Codes**: Select adjustment reason (damage, loss, etc.)
2. **Quantity**: Enter positive or negative adjustment
3. **Approval**: Manager approval required for adjustments
4. **Audit Trail**: Complete record of all changes

#### 🔄 Stock Transfers
1. **Source Location**: Select where stock is coming from
2. **Destination**: Choose where stock is going
3. **Products**: Select products and quantities to transfer
4. **Confirmation**: Both locations must confirm transfer

### Inventory Reports

#### 📊 Stock Reports
- **Low Stock Report**: Products needing reorder
- **Expiry Report**: Products approaching expiration
- **Stock Valuation**: Total inventory value
- **Movement History**: All stock movements

## Troubleshooting

### Common Issues

#### 🔐 Login Problems
- **Forgot Password**: Use "Forgot Password" link
- **Account Locked**: Contact administrator
- **Wrong Outlet**: Ensure correct outlet selection
- **Browser Issues**: Try clearing browser cache

#### 💳 Payment Issues
- **Card Reader**: Check card reader connection
- **Network**: Verify internet connection
- **Payment Gateway**: Check gateway status
- **Receipt Printer**: Ensure printer is connected and online

#### 📦 Inventory Issues
- **Stock Mismatch**: Run stock reconciliation
- **Missing Products**: Check product status (active/inactive)
- **Barcode Scanner**: Verify scanner connection
- **Sync Issues**: Refresh browser or restart system
